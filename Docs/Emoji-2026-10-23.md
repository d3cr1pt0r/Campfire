# Emoji — 2026-10-23

## User-facing behavior

- Every emoji in Campfire is drawn with **Noto Color Emoji**, so members on Windows, macOS and Linux see the same set: in messages, the composer while typing, reactions, the picker, names and code.
- The emoji picker has a **Search emoji** box (focused when it opens). Words match the start of an emoji's name, keywords or short names, so "laugh", "thumb", "flag slo" and "pepe" (for custom emoji) all work. Enter picks the first result.
- Without a search, the picker shows **Recently used** (up to 16, latest first, two rows in the dialog), then the server's **Custom** emoji, then all 1,923 standard emoji in nine groups. Hovering an emoji shows its short name.
- The message action bar shows the member's three **most used** emoji before the React button. Clicking one toggles that reaction; it is highlighted when the member already reacted with it.
- The composer shows the same three emoji beside the emoji button. Clicking one inserts it at the caret. Narrow composers (480 px or less, such as most thread panels) hide them to keep room for typing.
- Reactions can now use any standard emoji, not only the old list of about 260.
- Typing `:` suggests short names for every standard emoji (Slack/GitHub style, for example `:joy:` and `:+1:`), plus the older names and custom emoji.

## Most used and recent

- A use is a reaction the member adds (from the picker, a chip or the action bar) or an emoji in a message they send, counted once per message and ignoring code. Taking a reaction back is not a use.
- Only the last 50 uses count. The most used three rank by count within those uses, ties going to the latest; 👍 😂 ❤️ fill any gaps. Recently used lists distinct emoji from the same window.
- Uses are stored on this device for each server account (`emoji-usage:<server>:<member>`), like collapsed categories and direct-message pins. Deleted custom emoji drop out.

## Implementation

- `src/assets/fonts/noto-color-emoji.woff2`: Noto Color Emoji 2.057 (COLRv1, Emoji 18, release `v2026-09-24-unicode18_0`) compressed to WOFF2, 2.0 MB. Licence: `noto-color-emoji-OFL.txt`.
- `src/style.css`: the `Campfire Emoji` font face, first in `--font-ui` (and `--font-code` in `src/campfire-theme.css`). Its `unicode-range` leaves digits, `#`, `*`, ©, ® and ™ to the text font, and it loads only when an emoji appears.
- `scripts/emoji-data.mjs` generates `shared/emojis.js` from Emojibase 18.0.0 (MIT): groups, names, keywords and GitHub short names. The server accepts reactions from the same list (`server/messages.js`).
- `src/emojiUsage.ts`: the usage window, most used and recent emoji, and emoji found in sent messages.
- `src/EmojiPicker.tsx`: the picker, used by the emoji and reaction dialog (`src/main.tsx`) and the thread panel (`src/ThreadPanel.tsx`).
- `src/emojiCompletion.ts`: picker search and `:` completion. `src/ChatMessages.tsx` and `src/ChatComposer.tsx`: the most used emoji. Styles are in `src/campfire-theme.css`.

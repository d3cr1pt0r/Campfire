# GIF picker — 2026-10-21

## User-facing behavior

- When the server has a KLIPY key, every composer (channels, DMs and threads) shows a **GIF** button. It opens a picker above the composer with a **Search KLIPY** box, a **Trending** tab (named **Results** while searching) and a **Favourites** tab. Clicking a GIF sends it at once; Escape or clicking elsewhere closes the picker.
- Searching waits 400 ms after typing stops. Results load page by page as you scroll, keep KLIPY's order, and show "Powered by KLIPY".
- Each GIF has a star. Starred GIFs appear in **Favourites** (up to 200 per member). They are saved to your account on the server, so they follow you to every device. GIFs in chat can be starred too.
- A sent GIF is a message containing KLIPY's link. A message that is only a KLIPY media link shows the GIF inline, sized to its own shape within 480 × 360, and falls back to a "GIF unavailable" link if KLIPY no longer serves it.
- Errors are explained in the picker, including KLIPY's hourly limit for test keys.

## KLIPY's terms

This follows KLIPY's standard integration (docs.klipy.com/integration-requirements): members' apps call KLIPY and load its media directly, links are used exactly as returned, results keep KLIPY's order in their own tab, and the search box says "Search KLIPY". Sending searches through the Campfire server and saving sent GIFs as attachments need KLIPY's written approval, which has been requested. Until then the server only stores favourite links and sizes, never media.

## Setup

Set `KLIPY_API_KEY` in `.env` (see `.env.example`). The key is shared with signed-in members in `/api/state`, as client keys are. Without a key the GIF button does not appear.

## Implementation

- `shared/klipy.js`: KLIPY's media hosts and `isKlipyMedia` (HTTPS, no credentials or ports).
- `server/config.js`, `server/app.js`: the key, its `klipyKey` state field, and the media hosts in the image content security policy (also in `electron/renderer-server.cjs`).
- `server/gifs.js`, `server/schema.sql` (`gif_favorites`): favourites per member, validated as KLIPY links.
- `src/klipy.ts`: KLIPY search and trending requests, result conversion and GIF-message detection.
- `src/GifPicker.tsx`, `src/ChatComposer.tsx`, `src/ChatContent.tsx`, `src/main.tsx`, `src/ThreadPanel.tsx`: the picker (shown in a portal above the composer), the shared favourites store, GIF messages and sending. Styles are in `src/campfire-theme.css`.

Channel management, independent stream subscriptions, presence controls, and a broader interface refresh.

## Added

- **Watch / Stop watching** screen-share subscriptions: screen media is attached only for subscribed viewers while voice continues independently.
- Separate voice and shared-system-audio volume controls.
- Editable nicknames while account usernames remain permanent.
- Channel renaming, confirmed deletion of additional channels, and role-based full/read-only/hidden channel access.
- Protected default text and voice channels.
- Profile-picture crop preview with drag, zoom, center-crop, and fit controls.
- Confirmed custom-role deletion, with affected users moved to Member; Owner and Member roles remain protected.
- Manual Online, Idle, and Do not disturb statuses, plus optional automatic idle detection.
- Linux standalone AppImage/archive build support and a GitHub Actions packaging workflow.

## Changed

- Refreshed typography, spacing, controls, settings layouts, and narrow-window navigation.
- Improved keyboard access to message actions, dialogs, and media viewers.
- Added clearer friend/request filters, connection feedback, and search/pinned-message headings.
- Added paginated history and search/pinned filtering across the full conversation.
- Reorganized server/UI modules, pinned dependencies, and added CI formatting and regression checks.

## Fixed

- Prevented stale history responses from overwriting live messages, edits, or deletions.
- Normalized reversed DM room identifiers into one conversation history.
- Improved session-expiry enforcement and permission checks for message edits and channel operations.
- Fixed role-editor return navigation and settings control alignment.
- Improved multiline message editing and Enter handling during IME composition.
- Fixed Windows CI line-ending formatting issues.

## Server administration

- Added transactional database migrations and configurable aggregate attachment storage limits (1 GiB by default).
- Added asynchronous, bounded password hashing and explicit trusted-proxy configuration.
- Back up the database before upgrading. Restart the server and update all calling clients together: this release uses media protocol v2.

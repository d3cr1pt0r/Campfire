Message threads, smoother chat history, lighter image previews, and desktop usability improvements.

## Added

- Message threads: use **Reply in thread** from a message's hover actions or click its reply count to open the right-side panel.
- Thread replies support attachments, image previews, emojis, reactions, editing, deletion, pins, search, history pagination, and thread-scoped typing. Nested threads are disabled.
- Clipboard file/image pasting, including native desktop clipboard attachments, with review before sending.
- **LIVE** shortcuts beside screen-sharing voice-channel participants to join the channel and watch their stream.
- App icons for desktop builds and the browser favicon.
- An MIT license, a security review report, and historical release descriptions.

## Changed

- Virtualized message history renders nearby rows to reduce the cost of long conversations, with automatic older-history loading and a **Jump to latest** action.
- Image attachments use small, cached WebP previews loaded near the viewport. Full-resolution originals and animated GIFs load when opened or downloaded.
- Joining a call keeps the large call panel hidden by default. Showing or hiding it preserves voice playback and active stream subscriptions.
- Removed the desktop menu bar.
- The UI version and desktop build metadata now read from `package.json`. One `npm version ... --no-git-tag-version` command updates package and lockfile versions together.

## Fixed

- Improved native clipboard attachment handling for copied files and screenshots.
- Corrected participant initials in call views, including names containing Unicode characters.
- Avoided redundant audio-output switches and improved fallback when a selected output device becomes unavailable.
- Deferred audio-output setup until a media track is available.

## Upgrading

- Back up the server database, install dependencies, and restart the updated server before rebuilding/updating clients. Thumbnail previews require the updated backend and its Sharp dependency.
- Thread storage is added automatically through a database migration. Deleting a parent message also deletes its thread replies and their attachments.
- The security report documents existing risks and recommended mitigations; this release does not itself add HTTPS or end-to-end chat encryption.

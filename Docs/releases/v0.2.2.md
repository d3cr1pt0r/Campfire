Automatic desktop updates, local RNNoise suppression, live activation previews, more video quality controls, and clearer settings and call layouts.

## Added

- **Automatic desktop updates** for the Windows installer and Linux AppImage. Campfire checks for newer stable releases after startup and every four hours, then downloads updates in the background. A ready banner offers **Restart to update**, with confirmation before ending active calls or screen sharing. Downloaded updates also install on full quit; closing to the tray keeps the app running.
- **Client update controls** under **Settings → My account → Client updates**, including manual checks, download progress, and retry after a failure.
- **Desktop release preparation workflow** that builds Windows and Linux packages and attaches them, update metadata, and release notes to a draft GitHub Release for review before publication.
- **RNNoise noise suppression**, running locally on your device. Choose **RNNoise** or **Chromium** under **Settings → Audio & Video → Voice processing**. RNNoise is the default when no engine preference is saved; echo cancellation and automatic gain remain separate controls.
- **Speech-based voice activation** using RNNoise, alongside microphone-volume activation. Both modes have an **Activation threshold** slider with a live marker: microphone level in dBFS or speech confidence as a percentage. An advanced release-delay control helps preserve word endings.
- **Separate camera and screen-share quality settings.** Choose camera resolution up to 1080p at 15 or 30 fps. Screen sharing supports source resolution or limits up to 720p, 1080p, or 1440p, at 5, 15, 30, or 60 fps.
- **Advanced video bitrate and adaptation controls.** Set a bitrate ceiling for each viewer and choose whether a struggling connection should prioritize sharpness, smoothness, or a balance. Changes apply during an active call or share.
- **Live video diagnostics and reduced-quality warnings.** Inspect upload, download, latency, resolution, frame rate, bitrate, codec, and packet loss. Call and video-tile warnings help identify bandwidth or computer limits affecting a stream.

## Changed

- **Windows downloads now include a per-user installer**, the recommended option for automatic updates. The portable executable remains available with manual updates. Linux keeps the automatically updatable AppImage and manually updated tarball options.
- **Settings are easier to read**, with grouped navigation, clearer headings, shorter paragraph lines, and more consistent spacing and alignment. Audio settings separate microphone input, voice processing, input mode, playback, and video controls.
- **Messages appear above call details.** The divider resizes the call area below; dragging upward expands it. The minimum call height, including the divider, aligns with the sidebar's user controls.
- **Call headers are simpler.** The channel name and icon use the connected green tint, without the participant-count subtitle. Removed the separate sidebar connection box. The LIVE badge sits beside the channel name and appears only while you are sending camera video or sharing a screen. The red leave-call button is last in the control row.
- **Participant tiles keep consistent 16:9 proportions**, with centered rows and circular avatars that scale down in smaller tiles. Focus view gives the selected video or stream the main area, with participant avatars in a strip below.
- **Microphone previews run automatically** while Audio & Video settings are open. Removed the manual start/stop test buttons; resume and retry controls appear when needed. In-call previews reuse existing microphone processing, and standalone preview capture stops when settings close.
- **Channel and category editors open on Overview.** Explicit permission links still open Permissions, and unsaved permission changes remain protected when navigating.

## Fixed

- Fixed account deletion failures caused by SQLite parameter binding on older supported Node versions.
- Fixed activation sliders requiring a manually started microphone test before displaying a live level.
- Restored a live preview for speech-based activation, using RNNoise's speech confidence rather than microphone volume.

## Upgrading

- Download the Windows installer or Linux AppImage manually for this first updater-enabled version. Subsequent stable client releases can update automatically. Keep Linux AppImages in a user-writable directory. Server updates remain manual.
- Existing Campfire profiles remain available when switching from the portable Windows executable to the installer. See [Desktop updates](../DesktopUpdates.md) for package choices and release preparation instructions.
- Update the server and clients together, rebuild browser assets, and restart the desktop app to load the new controls and bundled RNNoise assets.
- This release does not change the v0.2.1 database schema. Keep your existing v0.2.1 data and back it up before updating. For earlier installations, see the [v0.2.1 upgrade notes](v0.2.1.md#upgrading).
- Existing saved engine choices are preserved. Selecting RNNoise replaces Chromium noise suppression while leaving echo cancellation and automatic gain independently configurable.

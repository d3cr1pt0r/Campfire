Microphone recovery, voice playback, and call diagnostics improvements.

## Added

- A visible **Play audio** action when automatic playback is blocked.
- **Call details** showing connection/ICE state, audio direction, packet counters, and available audio levels.
- More useful microphone error messages and troubleshooting guidance.

## Fixed

- Improved recovery when a saved microphone device is disconnected or its device ID changes, using System default where appropriate.
- Improved voice negotiation by coordinating initial offers, serializing signaling, and queuing early ICE candidates.
- Separated remote audio playback from muted video previews so camera/screen changes do not replace the audio playback element.
- Improved recovery from unavailable saved output devices and made participant volume controls visible without hovering.

Update both clients for the voice changes. STUN alone does not guarantee connectivity across every NAT/firewall; some networks still require TURN.

Initial Campfire release: self-hosted community chat with a shared browser interface and a Windows x64 portable desktop client.

## Added

- Server-local accounts, registration/sign-in, persistent sessions, and role-based permissions.
- Text channels, direct messages, friend requests, online presence, and live message delivery.
- File attachments, message editing/deletion, reactions, typing indicators, unread badges, search, and pinned messages.
- Peer-to-peer voice channels, webcam video, screen/window sharing, mute/deafen, push-to-talk, and participant volume controls.
- Settings for notifications, audio devices, and requested streaming resolution.
- Standalone server and Docker deployment, plus a Windows portable build command and GitHub Actions workflow.
- Desktop settings/session persistence across relaunches and replacement of the executable.

This is an early private-community release. Internet hosting requires an HTTPS reverse proxy; DMs are not end-to-end encrypted. Screen sharing in this version does not capture system audio.

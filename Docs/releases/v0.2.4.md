Persistent unread notifications, easier navigation through missed messages, a searchable emoji picker, and a steadier desktop layout.

## Added

- **Unread badges survive restarts and time offline.** Missed activity is stored on the server, and clearing it syncs across your devices. Reconnecting restores badges without replaying old sounds or desktop alerts.
- **Jump through missed messages.** Click a channel or DM with pending notifications to visit its newest unread message. Repeated clicks move through the remaining messages, newest first. Thread replies open in the thread panel, with both the reply and its original message highlighted.
- **Clear notifications from the sidebar.** Right-click a text channel, DM, or member and choose **Clear notifications**. Keyboard users can use Shift+F10 or the context-menu key.
- **Searchable emoji picker** with recently used emoji, server custom emoji, and a larger grouped collection of standard emoji. Search by name or keyword, then press Enter to choose the first result. Short-name completion with `:` also supports the expanded collection.
- **Personalized quick reactions** show your three most used emoji in the message action bar.
- **Show role colors** in Appearance settings, enabled by default.

## Changed

- Notification rules for server mute, channel/category overrides, and DMs now save to your server account and sync across devices. Existing local rules are imported on first connection when no account rules are saved. Sounds, output devices, and desktop-alert permission remain local.
- Opening or focusing a conversation preserves its missed-message backlog. A notification jump highlights and clears queued messages visible in the chat or open thread; offscreen messages remain pending. New messages in the visible, focused conversation are acknowledged individually. Muting and Do not disturb silence alerts while retaining unread badges.
- Emoji use the bundled Noto Color Emoji font for consistent rendering across platforms. Reactions support the expanded standard emoji collection.
- Message times appear after the text in 24-hour format. Repeated times within the same minute are hidden until hover or keyboard focus.
- Call panel expansion uses a consistent starting size, with clearer collapse and resize behavior.
- The composer keeps emoji insertion in the picker; quick emoji shortcuts beside the composer have been removed.

## Fixed

- The desktop tray icon is available from startup and stays visible while the app window is open.
- The desktop top bar stays on one row when narrowing the window, and the members panel keeps its 248px width. The members overlay is reserved for browser windows below 800px.

## Upgrading

- Update the server and clients together, rebuild and deploy browser assets, and restart the desktop app. Server updates remain manual. See [Desktop updates](../DesktopUpdates.md) for supported automatic client updates and manual package choices.
- Back up your server data before updating. Existing v0.2.3 databases are retained; startup adds notification tables and initializes existing message history as read. New activity is tracked from then on.
- Setup capture/reset does not preserve personal server notification rules or read positions. A reset clears them along with message history. See [Server setup capture/reset](../ServerSetupReset.md).

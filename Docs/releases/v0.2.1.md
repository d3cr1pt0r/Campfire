Channel categories, richer messages, redesigned notifications and settings, and more control over audio and server storage.

**Upgrade note:** v0.2.1 does not open the v0.2.0 database schema. Back up your server data before updating and read **Upgrading** below.

## Added

- **Channel categories** for mixed text and voice channels, with collapsible groups and unread counts that remain visible when collapsed. Organize categories and channels in **Settings → Channels**, using drag-and-drop or Alt + Arrow keys.
- **Shared category permissions.** Channels can follow their category's permissions or keep custom permissions. Moving a channel offers an explicit choice, and custom channels can be synced again later. Private categories, role overrides, and permission explanations use the existing access controls.
- **Polls** in channels, DMs, and threads, with up to ten answers, single or multiple selections, public or anonymous voting, and a choice of closing time. Results appear after voting.
- **Live message formatting**, with a formatting toolbar and support for headings, lists, quotes, links, inline code, code blocks, and spoilers.
- **Voice-channel invitations** sent through DMs. Search for a member, send an invitation, and join the named channel from the message. Voice and private-call invitations share the same compact member picker.
- **Personal DMs.** Open your own entry in the member list to keep private notes and files. Self-messages stay read and never ring or start a self-call.
- **GIF search and favourites**, available when the host configures `KLIPY_API_KEY`. Favourites are saved per account on the server.
- **Link previews** for supported web links, with preview images and page details when available.
- **Animated profile-picture frames**, with a server setting to enable or disable them.
- **Password recovery** through one-time tokens created by an authorized administrator. Completing a reset signs the member in with a fresh session.
- **Message and attachment retention controls** under **Settings → Server settings**, with server defaults, channel overrides, and a separate DM period. Keep messages forever, remove older messages, or keep text while removing only its files. Preview the effect before saving; shorter periods normally give a week's notice, with a separately confirmed option to apply immediately. Pinned messages are kept.
- **Attachment storage controls**, including an owner-configurable per-message upload limit, a server-wide storage allowance, and a storage overview.
- **Server setup capture and reset tools** for rebuilding a fresh database while retaining supported account and configuration settings. See the [setup capture/reset guide](../ServerSetupReset.md) for what is preserved and what is cleared.

## Changed

- **Notifications have their own redesigned settings page.** Set a server default of All messages, Mentions only, or Nothing; categories and channels can inherit or override it. The override section shows the category/channel hierarchy with dropdowns beside each row, without reordering controls or category channel counts.
- **DM notifications have a separate default and searchable conversation overrides.** Desktop alerts and message sounds can be controlled independently. Server mute and Do not disturb silence alerts and ringing while leaving messages and unread indicators available.
- **Settings use a more consistent, compact layout**, following My account, with stable window width and clearer grouping. Channel and category editing use a nested organizer beside the selected item's editor. Access permissions are managed in Channels, alongside the channel itself.
- **Channel creation and organization are centralized in Settings → Channels.** Removed sidebar creation and settings shortcuts, and disabled sidebar reordering. Messages appears first in the left navigation. Existing single-line DM and joined voice-user rows are retained, and voice invite icons remain visible.
- **Member lists share compact identity rows** across settings, invitation pickers, mention suggestions, and reaction/voter popups. Member management groups account actions beneath each member, including disabling, restoring, password recovery, and permanent deletion where permitted.
- **Audio & Video settings** group input/output devices, microphone and output volume, sound-effects volume, noise suppression, echo cancellation, automatic microphone gain, push-to-talk, and voice activation. A live microphone meter helps set the activation threshold. Individual participant volume controls remain available during calls.
- **Distinct notification and call sounds**, including a softer kalimba-style DM sound and incoming-call ringing.
- **Compact messages are the default**, with additional avatar display options. Image attachments follow their proportions, and animated images play inline.
- **Sign-in starts with the server address**, with account fields shown after the server is resolved. Desktop HTTP access has a remembered opt-in for each exact server address and port; HTTPS remains the default.
- **New roles copy Default's server permissions and color**, without copying its channel-specific overrides.
- **Attachments are stored as raw bytes**, and message searches run on worker threads to keep the server responsive.

## Fixed

- Dragging through a long channel organizer scrolls at its upper and lower edges, allowing items to move beyond the visible area.
- Switching between settings pages no longer changes the window width.
- Avatar images are shared and cached across messages and desktop restarts, reducing repeated downloads. Profile pictures no longer show a colored fringe around their edges.
- Reopening an invitation picker clears its search and delivery state so a fresh invitation can be sent. Pending responses from a previous opening do not change the new picker.
- Voice invite icons are no longer obscured by sidebar settings shortcuts.
- Voice invitation modules no longer collide by filename on Windows.
- Setup capture/reset preserves channel definitions, ordering, category membership, and permission-sync choices.

## Upgrading

- **Update the server and clients together.** Rebuild browser assets and restart the desktop app to load the new controls.
- **Back up the complete server data directory, including `data/identity/`, before updating.** Automatic database migrations have been removed. The old v0.2.0 schema is refused rather than modified in place; start with a fresh data directory or use the documented [setup capture/reset workflow](../ServerSetupReset.md) where supported.
- **Setup capture/reset is not a message-history migration or a full backup.** It preserves supported account and configuration data, but clears messages, attachments, polls, avatars, custom emojis, GIF favourites, sessions, invitations, and recovery tokens. Account and custom channel/role IDs are regenerated. The capture tool must understand the source database; arbitrary older schemas are not guaranteed to be compatible. Keep the original backup and identity files.
- Message retention defaults to keeping messages forever. Review server and channel periods before enabling deletion; applying a shorter period immediately can permanently remove existing content.
- GIF search is optional and stays hidden until the host configures `KLIPY_API_KEY`.

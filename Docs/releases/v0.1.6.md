More compact channel management, @mentions, configurable message notifications, and reliable server shutdown.

## Added

- **@mentions** with permanent-username autocomplete in chat and threads. Use Up/Down to select a result, Enter to insert it, or Escape to dismiss. Mentions are highlighted in messages.
- A soft notification chime for incoming DMs and direct mentions, including thread replies.
- Notification preferences for sounds, DMs, direct mentions, and individual text channels or DM conversations. Do not disturb silences both message sounds and desktop alerts.
- Persistent text/voice channel ordering through up/down controls in **Settings → Channels & access**, restricted to roles with **Manage server, channels, roles & messages** permission.

## Changed

- Channel settings now list text channels before voice channels and expand one compact editor at a time, reducing vertical clutter.
- Clicking the name of a voice channel you have already joined toggles call details without leaving the call.
- Background desktop message notifications now target DMs and direct mentions; ordinary channel messages do not trigger alerts.
- Clarified that the green dot beside message search indicates the server connection.
- Clarified the existing microphone processing in Voice & video settings: Chromium's built-in noise suppression, echo cancellation, and automatic gain control. The audio-processing implementation is unchanged.

## Fixed

- Fixed the shutdown path that could close SQLite twice and report **database is not open** after Ctrl+C.
- Repeated shutdown calls share one cleanup operation, and repeated SIGINT/SIGTERM signals no longer start duplicate cleanup.

## Upgrading

- Restart the updated backend and rebuild/update clients. Migration 6 preserves the existing channel order within each type and adds persistent ordering.
- Message sounds and DM/mention subscriptions default to enabled; desktop notifications require opt-in and OS permission. Sound playback requires an initial interaction with the app.
- Preferences are saved on the current device. Per-conversation overrides are scoped to the account and server and also apply to thread replies.

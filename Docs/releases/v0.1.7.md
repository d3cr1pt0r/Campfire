Owner-controlled registration, more detailed role permissions, and channel access configured directly from each role.

## Added

- **Free for all / Invite only** registration under **Settings → Server settings → Who can join**, controlled only by the owner. Existing members can sign in in either mode.
- Single-use invitations with optional labels, seven-day expiry, copyable codes/browser links, and revocation. Invitation codes are displayed once and stored as hashes; new accounts receive the Member role.
- A random **owner setup code** printed in the server console, required to create the first account on a new server. Restarting an unclaimed server generates a new code.
- **22 granular role permissions** grouped into Messaging, Message moderation, Calls, Channels, Custom emojis, and Server. Posting, uploads, reactions, threads, message moderation, channel administration, and server settings can now be delegated independently.
- Separate call permissions for joining, starting direct calls/inviting friends, speaking, camera video, and screen/audio sharing. Listen-only joining does not request microphone access.
- Editable text-channel descriptions, up to 200 characters, displayed beside the channel name. Edit them under **Settings → Channels**; leave the description empty to hide it.

## Changed

- Renamed **Channels & access** to **Channels**. This page now handles channel names, descriptions, ordering, and deletion.
- Moved channel-access controls into **Roles & permissions → Edit role**. Each role has a channel table with **Full access / Read only / Hidden** for text channels and **Visible / Hidden** for voice channels.
- Role creation, general permission changes, deletion, and assignment are now **owner-only**. The separate **Change role access to channels** permission allows delegated editors to change only the access table, limited to channels they can already see.
- New servers default to **Invite only**. Existing servers with accounts retain open registration until the owner changes it. Switching to Free for all requires confirmation and revokes unused invitations.
- Own-message editing and deletion have independent permissions. Members with **Delete own messages** can remove their own content in visible read-only channels, even without posting permission. Message moderation does not allow deleting another author's DM.
- Role and channel-access changes apply to active sessions. Revoking call access ends the call; revoking publishing permissions stops active capture in the official client. Newly granted speaking permission can be activated with **Unmute microphone**.
- Removed the member-list promotional card, its copy-server-address button, and the “Your server. Your conversations.” footer text.

## Fixed

- Vertically aligned the message search field, magnifying glass, pinned-message/member/call buttons, and server-connection indicator in the top bar.

## Upgrading

- Back up the server database, restart the updated backend, and **update/rebuild all clients together**. Older clients do not understand the new permission names.
- Migrations 7–9 add registration controls, channel descriptions, and detailed permissions. Existing role assignments and channel-access overrides are preserved; old Send/Voice/Manage flags expand into the new feature permissions. Review delegated roles because general role administration is now owner-only.
- For a fresh server, retrieve the owner setup code from its console or `docker compose logs campfire` before creating the owner account. Existing owners do not need this code.
- HTTPS remains necessary for remote sign-up and use. This release does not add automatic HTTPS or end-to-end chat encryption. Media publishing controls enforce official-client behavior and declared signaling; the server does not inspect encrypted peer-to-peer media and cannot strictly police publishing by modified clients.

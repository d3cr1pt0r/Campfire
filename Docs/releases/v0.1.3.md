Expanded media viewers, richer messaging, direct calls, and microphone testing.

## Added

- Large video/screen-share viewing with fullscreen support.
- Windows desktop screen-sharing system audio, with a share-audio option in the source picker.
- A microphone test with a live input meter in Voice & video settings.
- Profile pictures, inline image/GIF previews, and an expandable image viewer.
- Clickable HTTP(S) links, over 200 standard emojis, custom emoji uploads, and expanded message reactions.
- Direct calls to accepted friends and group invitations for private calls.
- Microphone activity indicators on call tiles and voice-channel avatars.
- Multiple-file uploads with review before sending: up to 10 files and 5 MB combined per message.

## Changed

- Remembered input/output devices with recovery when device IDs change.
- Voice-channel names now support capitals and spaces.

## Fixed

- Improved microphone-meter startup by resuming analysis from the user's action and handling device changes and cleanup more carefully.
- Improved stereo input analysis, including opposite-polarity and right-channel-only input.
- Removed stray numeric zeroes from message metadata when pin/edit flags are unset.

Windows system-audio capture is supported; Linux desktop system-audio capture is not implemented. Browser screen-share audio depends on platform and picker support.

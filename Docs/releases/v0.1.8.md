An updated theme, more flexible call layouts, and new chat, notification, and desktop controls.

## Added

- **Light, Dark, and System appearance** options under **Settings → My account**, saved on this device and applied to the sign-in screen as well as the main app.
- **Emoji autocomplete** in conversations and threads. Type `:` to search built-in aliases and custom server emojis; use the arrow keys to select, Enter or Tab to complete, and Escape to dismiss.
- **Keyboard shortcuts:** Ctrl/Cmd + F for conversation search, Ctrl/Cmd + comma for settings, Ctrl/Cmd + Shift + M to toggle microphone mute during a call, and Ctrl/Cmd + Shift + D to toggle deafen.
- **Server icons** with upload, crop, pan, zoom, and fit controls, plus an option to adjust an existing icon.
- **Mute server** in notification settings and a conversation-toolbar mute button. Server mute suppresses message sounds and desktop alerts, including DMs and mentions, while keeping unread indicators visible.
- **Close to system tray** as an opt-in desktop setting. Closing the window keeps the session running; the tray offers Open and Quit, and launching another instance restores the window.
- **Owner-controlled member removal and restoration** in Server settings. Removing a member preserves message history, revokes sessions, disconnects calls, and blocks sign-in until access is restored. Restored members must sign in again.
- Microphone-muted and deafened indicators in voice rosters, plus a **CAM** badge that opens the corresponding camera call.

## Changed

- Updated the theme across chat, calls, sign-in, settings, and dialogs, with warmer colors, refreshed backgrounds, and revised spacing and controls.
- Calls now occupy a **resizable section above the conversation**, with a compact call header and expandable participant view. Drag the divider or use its arrow-key controls to adjust the space; Home collapses call details.
- Participant cards adapt to the available call area. Call controls, connection details, and the transition between compact and expanded layouts have been reorganized for easier use alongside chat.
- Channel ordering now uses **drag handles** with an insertion preview and before/after placement within each channel type. Focus a handle and use Alt + Arrow keys for keyboard reordering.
- Reaction chips show compact emoji counts. Hover or keyboard-focus a chip to see participant names and avatars in a popup; Escape dismisses it. Server and text-channel settings can hide these names. These settings affect display, not identity privacy or permission to react.
- Thread reply counts appear below reactions with more spacing.
- Scrollbars use transparent tracks and reveal their thumbs on hover or keyboard focus while the window is active, with space reserved to avoid layout shifts.

## Fixed

- Each text channel remembers its **reading position during the app session**, including older loaded messages. Channels left at the bottom reopen at the latest messages.
- Microphone tests use independent local capture, so call mute, deafen, and push-to-talk no longer silence the test or change what is transmitted to the call. Simultaneous capture depends on device and OS support.
- Improved channel dragging for adjacent moves and moves to the first or last position, with saved ordering protected against concurrent drags.
- Revoked invitations no longer occupy the invitation list or its query limit. Revoking a newly displayed invitation also dismisses its code.
- Existing community databases are reused when the default database is absent or has no accounts. If multiple alternative databases contain accounts, startup asks the host to select one instead of choosing arbitrarily.
- Improved call-detail and message-area resizing, including participant sizing and smoother expand/collapse transitions.

## Upgrading

- Stop the backend and back up the complete data directory, including SQLite WAL/SHM files, before updating. Restart the backend and update/rebuild clients together. Migration 10 adds per-channel reaction-name display, enabled by default.
- A populated `campfire.sqlite` takes precedence. Otherwise, the server reuses a single existing `.sqlite` database containing accounts. If startup reports multiple candidates, select the intended database while stopped; see the [upgrade guide](../../REWORK.md#configuration-and-database-upgrades).
- Docker Compose uses the `campfire` service and `campfire-data` volume. Existing installations must point that volume at their existing data volume before starting to retain their community data.
- To retain settings when moving to a new desktop profile, fully close the app and copy the previous user-data directory into the Campfire profile. Signing in again may be required. Rebuild the desktop shell and renderer together.
- Appearance, server mute, and close-to-tray preferences are device-local. Close to system tray is off by default; saved push-to-talk preferences remain respected.
